# ✈️ PSTAR & ROC-A Trainer

A cross‑platform (**iOS · Android · Web**) study app for Canada's **PSTAR** and **ROC-A** exams —
*Student Pilot Permit or Private Pilot Licence for Foreign and Military Applicants,
Aviation Regulations* — built with **Expo / React Native**.

**🌐 Live web app:** https://wonmor.github.io/pstar-prep/ · **Privacy:** https://wonmor.github.io/pstar-prep/privacy.html

All **185 official questions** across **14 sections** are sourced directly from
Transport Canada **TP 11919E, 7th Edition (Dec 2022)** and its answer key, each with
the verified correct answer and the original CARs / TC AIM study reference.

## Study modes

| Mode | What it does |
|------|--------------|
| 📝 **Mock Exam** | 50 random questions, **90 % pass mark** — just like the real PSTAR. Answers revealed at the end with a full miss‑review. |
| 🎯 **Practice Quiz** | Drill any single section with **instant** correct/incorrect feedback and the reference. |
| 🗂️ **Flashcards** | Tap to flip — front shows the question, back reveals the answer + reference. Mark cards as *mastered*. Decks: all, bookmarked, or per‑section. |
| ✅ **Answer Key** | Browse **every** question with the correct option marked **✓**. Full‑text search + section filters. |

Progress, per‑section accuracy, bookmarks (★) and best exam score persist locally
(`AsyncStorage`).

## Design

Bauhaus: strict grid, flat primaries (red / blue / yellow), heavy geometric type
(**Jost**, a Futura‑style grotesk), thick rules, no gradients or shadows. Structure
comes from colour fields and rules; every icon is an iOS‑style line glyph
(Ionicons outline set via `@expo/vector-icons`, names in `glyph` in
`src/theme.ts`) — no circles, squares or triangles as ornaments. Display type keeps
lineHeight ≥ 1.15 × fontSize so Jost's tall caps never clip. **Black** is the default
theme; **Paper** (off‑white) can be chosen in About. All text pairs are WCAG AA in
both themes. Tokens live in `src/theme.ts`. The app icon and in‑app brand mark
(outline aircraft on a blue field over yellow/red bands) are generated by
`node scripts/bauhaus_icon.mjs`.

## Free vs Pro

| | Free | Pro |
|---|---|---|
| Practice, flashcards, answer key | first **3 sections** of each exam | all sections |
| Mock exam | **1 per day** per exam | unlimited |
| Bookmarks, progress | ✓ | ✓ |

One `pro` entitlement covers both PSTAR and ROC‑A. Sold as
`pstar_pro_lifetime` (one‑time, non‑consumable; on the App Store it is `pstar_pro_lifetime_ios` because the original id was already taken in the account) and `pstar_pro_1month`
(auto‑renewing monthly). The **web build is fully free** (no payments on the web).

* Rules: `src/gating.ts` (pure, unit‑tested) · state: `src/entitlements.tsx`
  (`useEntitlements().isPro`, `useGate()`) · store: `src/purchases.ts`
  (RevenueCat) / `src/purchases.web.ts` (no‑op).
* Keys: `EXPO_PUBLIC_REVENUECAT_IOS_KEY` / `EXPO_PUBLIC_REVENUECAT_ANDROID_KEY`
  (see `.env.example`). Without a key — or in Expo Go — the paywall shows
  “Store unavailable” and the free tier keeps working.
* `react-native-purchases` is a native module: test purchases in an EAS
  development/preview build, not Expo Go.
* QA overrides: `EXPO_PUBLIC_FORCE_PRO=1` (native) · web query
  `?tier=free` (preview the free tier), `?tier=pro`, `?store=demo` (fake prices
  on the paywall), `?theme=light|dark`.

## Run it

```bash
cd pstar-prep
npm install

npm run web       # browser  → http://localhost:8081
npm run ios       # iOS simulator (needs Xcode)
npm run android   # Android emulator (needs Android Studio)
npm start         # dev server → scan the QR with Expo Go on a real device
```

### Native builds

`app.json` is configured with bundle id **`com.orchestrsim.pstarprep`** (iOS &
Android). To produce store binaries:

```bash
npm install -g eas-cli
eas build --platform ios      # or android / all
```

## Regenerating the question bank

The dataset was extracted from the two official PDFs:

```bash
pdftotext -layout tp11919e_-_7th_edition_dec2022.pdf       questions.txt
pdftotext -layout tp11919e_-_pstar_answer_key_english_dec2022.pdf answers.txt
python3 scripts/parse_pstar.py            # → pstar.json (185 Qs, all validated)
```

The parser merges questions, options, the answer key, and the study‑reference
appendix, and validates that every question has 4 options and an in‑range answer.
